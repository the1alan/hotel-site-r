# 🏨 Hotel Site

Демо: https://hotel-site-r.onrender.com

## Стек
- Node.js + Express
- MongoDB Atlas
- Docker + Docker Compose
- Render.com

## Локальный запуск
\`\`\`bash
docker-compose up
\`\`\`

## Логин
admin / 123

## Маршруты
- `/` - главная
- `/rooms` - номера
- `/login` - вход
- `/admin` - админ-панель (admin/123)
